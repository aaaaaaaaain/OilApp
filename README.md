# 油耗紀錄 App ⛽

記錄每次加油的里程與公升數，自動算出油耗（km/L）。純前端網頁，資料存在瀏覽器裡，不上傳任何伺服器。

## 功能

- **多車輛**：右上角可切換車輛，每台車的紀錄、統計與圖表分開計算；車牌／車名在設定頁新增與修改

- **兩種輸入模式**
  - 直接輸入里程：這趟開了幾公里 ÷ 加了幾公升
  - 總公里數計算：只要抄里程表讀數，App 自動跟上次相減
- **加油金額（選填）**：單價、公升、金額三欄互相補完 —— 填單價和公升自動算金額，直接改金額則回推單價；單價會記住，下次開 App 自動帶入
- **統計卡片**：平均油耗、總筆數、歷史新低；有記金額時多一排總油錢、平均花費、每公里成本。點一下可收合成一行，條碼與表單會往上移，收合狀態會記住
- **折線圖**：油耗變化趨勢，附平均油耗虛線；點圓點可看該次的完整日期時間、里程與花費（Chart.js）
- **歷史明細**：每筆顯示油耗、與上一筆的增減（↑↓）、間隔天數，可編輯／刪除
- **JSON 備份／還原**：設定頁可匯出備份檔，換手機或清除瀏覽資料後再匯入還原（含紀錄與設定）
- **匯出 Excel**：含每筆明細與總計列（總公升、總里程、總平均、總金額、平均油價、平均每公里成本）
- **載具條碼**：輸入 7 碼手機載具代碼，產生 CODE128 條碼，加油時直接給店員掃。代碼在右上角 ⚙ 設定裡填，實際要掃的條碼固定顯示在「新增」頁下方
- **設定頁**：右上角 ⚙ 進入，分為外觀／載具／資料／關於四區
- **外觀**：跟隨系統／淺色／深色三選一，選過會記住
- **可安裝、可離線**：具備 PWA manifest 與 Service Worker，加到主畫面後全螢幕開啟；
  第一次連上網後函式庫會存進快取，之後沒訊號也開得起來（加油站掃條碼不怕沒網路）

## 使用方式

線上直接用（若已開啟 GitHub Pages）：

```
https://aaaaaaaaain.github.io/OilApp/
```

或本機開啟：

```bash
git clone https://github.com/aaaaaaaaain/OilApp.git
cd OilApp
python -m http.server 8123
```

然後瀏覽器打開 http://localhost:8123

> 建議用本機伺服器開啟，直接雙擊 `index.html` 在部分瀏覽器會擋掉外部函式庫。

## 計算方式

| 情況 | 行駛里程 | 油耗 |
| --- | --- | --- |
| 直接輸入里程 | 你填的里程 | 里程 ÷ 公升 |
| 總公里數，第一筆 | 里程表讀數（從 0 起算） | 讀數 ÷ 公升 |
| 總公里數，第二筆之後 | 這次讀數 − 上次讀數 | 里程 ÷ 公升 |

金額相關（金額留空的紀錄不列入計算）：

| 項目 | 算法 |
| --- | --- |
| 金額（自動） | 單價 × 公升 |
| 單價（自動） | 金額 ÷ 公升 |
| 每公里成本 | 金額 ÷ 行駛里程 |
| 總油錢 | 有填金額的紀錄加總 |
| 平均花費 | 總油錢 ÷ 有填金額的筆數（每次加油平均花多少） |
| 每公里成本（統計卡片） | 有金額也有里程的紀錄：總金額 ÷ 總里程，不含「起始」那筆 |

- 上方「平均 km/L」= 所有算得出油耗的紀錄取平均
- Excel 的「總平均」= 總里程 ÷ 對應的總公升數（加權平均，跟上方數字算法不同）
- 紀錄會依日期時間自動排序，插入舊日期的資料也會重新計算

> 若你的車是中古車、里程表已經有幾萬公里，第一筆會算出偏高的數字，把它當基準看第二筆之後即可。
> 上方「每公里成本」已自動排除這筆，不會被拉低。

單價和金額都是選填，不填照樣能用；沒有任何一筆填過金額時，那排金額卡片不會出現。改版前的舊紀錄沒有金額欄位，會照常顯示，之後用「編輯」補填即可。

## 檔案結構

```
index.html   主頁（圖表＋歷史明細同一頁）＋右上角設定頁＋右下角新增鈕
             新增紀錄是蓋滿畫面的彈出視窗，開 App 會自動跳出，
             載具條碼固定在視窗最上方，一打開就能直接掃
style.css    iOS 風格樣式，含深色模式
script.js    全部計算、儲存、圖表、匯出、條碼、主題切換邏輯
             檔案開頭的 APP_VERSION 就是設定頁顯示的版本號
fuel.png     App 圖示（512×512）
manifest.json  PWA 設定：名稱、圖示、全螢幕顯示
sw.js        Service Worker：離線快取。改版時要同步更新裡面的 CACHE 版號與 ?v=
vendor/      Chart.js、SheetJS、JsBarcode 的本機副本（不走 CDN，離線才能用）
build-www.js 把網頁檔案複製到 www/ 給 Capacitor 打包
android/     Capacitor 產生的 Android 專案
```

## Android APK

用 [Capacitor](https://capacitorjs.com/) 把同一份網頁檔案打包成原生 App，
所有檔案都在 APK 裡，裝好就能離線用，不需要連網也不依賴 GitHub Pages。

第一次需要的環境：Node.js、JDK 17、Android SDK（build-tools 34、platform 34）。

```bash
npm install
npm run apk
```

產出位置：`android/app/build/outputs/apk/debug/app-debug.apk`

把檔案傳到手機安裝即可（Android 會要求允許安裝未知來源的 App）。
這是 debug 簽章版本，自己用沒問題；要上架 Google Play 才需要另外建立正式簽章金鑰。

> 改版後要重新跑 `npm run apk` 並重新安裝，APK 不會像網頁版那樣自動更新。

## 資料儲存

所有紀錄存在瀏覽器的 `localStorage`：

| Key | 內容 |
| --- | --- |
| `vehicles` | 車輛清單（id 與車牌） |
| `fuelData` | 每台車的加油紀錄 |
| `activeVehicle` | 目前選到的車輛 |
| `carrierCode` | 載具代碼 |
| `inputMode` | 上次用的輸入模式 |
| `unitPrice` | 上次填的油價單價（元/L） |
| `theme` | 外觀設定（system／light／dark） |

因此：

- 換瀏覽器、換手機、清除瀏覽資料 → 紀錄會不見，記得定期到 ⚙ 設定用「匯出備份檔」備份
- Excel 是給人看的報表，**還原要用 JSON 備份檔**（設定 → 資料 → 還原備份檔）
- 還原會取代目前全部紀錄，不是合併
- 「重置資料」會清空紀錄，無法復原
